# Política de seguridad

Si encuentras una vulnerabilidad, una clave expuesta o un dato personal en este
repositorio, **no abras un issue público**. Repórtalo en privado desde la pestaña
**Security → Report a vulnerability** de este repositorio en GitHub.

- Respuesta inicial objetivo: dentro de 7 días.
- Este repositorio no debe contener secretos ni datos de clientes. Si encuentras
  alguno, reportarlo por el mismo canal es lo correcto y se agradece.
- Alcance: el código y los archivos de este repositorio. No se prueban sistemas
  de terceros ni de producción de otras personas.
