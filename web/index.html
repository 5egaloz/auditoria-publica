Manifiesto de artefactos

Registro append-only de cada archivo descargado de una fuente oficial: URL, fecha de captura (UTC), tamaño y SHA-256. Cada entrada incluye el hash de la entrada anterior (cadena): alterar el pasado rompe la cadena. El archivo original queda guardado intacto en data/raw/ del repositorio.

Verificar

Las dos verificaciones corren completas en su navegador (Web Crypto API). Nada se envía a ningún servidor.

1 · Verificar la cadena del manifiesto

Re-calcula el hash de cada entrada del manifiesto y valida el encadenamiento (sha256_prev). Detecta cualquier entrada alterada, borrada o reordenada.

2 · Verificar un archivo contra el manifiesto

Descargue un artefacto desde su fuente oficial (columna URL del manifiesto) o desde data/raw/ del repositorio, y suéltelo aquí: su SHA-256 se calcula localmente y se busca en el manifiesto.

Método

Principios

  1. Neutralidad: el sistema no concluye "quién tiene razón"; publica magnitudes con base de comparación explícita, sin adjetivos valorativos.
  2. Verificabilidad: toda cifra apunta al hash SHA-256 del artefacto oficial del que salió, con hoja y celda (o campo XML) de origen.
  3. Reproducibilidad: cualquier persona puede re-descargar las fuentes, re-calcular los hashes y re-derivar cada cifra. El repositorio incluye los scripts.
  4. Simetría: las mismas reglas para todo gobierno, coalición o período.
  5. Si no hay dato, se dice "sin dato disponible". Nunca se estima ni se rellena.

Flujo

descarga del original → SHA-256 → data/raw/ (intacto, jamás editado) → manifiesto append-only con hash-chain → extracción a JSON (cada cifra con origen) → esta página
